# Bienvenido a MD Viewer

Un visor y editor **sencillo** de archivos *Markdown*, hecho con Tauri + Rust.

## Atajos

| Atajo | Acción |
|-------|--------|
| `Ctrl+N` | Nuevo |
| `Ctrl+O` | Abrir |
| `Ctrl+S` | Guardar |
| `Ctrl+Shift+S` | Guardar como |
| `Ctrl+E` | Cambiar vista (Editar / Dividido / Vista) |

# MD Viewer

Visor y editor sencillo de archivos Markdown hecho con Tauri 2 + Rust.

- Vistas: Editar, Dividido (vista previa en vivo) y Vista
- Asociación con `.md` / `.markdown` al instalar
- Atajos: `Ctrl+N`, `Ctrl+O`, `Ctrl+S`, `Ctrl+Shift+S`, `Ctrl+E`

## Desarrollo

```sh
npm install
npm run dev     # modo desarrollo
npm run build   # instaladores en src-tauri/target/release/bundle/
```
